# Публикация «ХРОНОЛИФТ» на Яндекс Игры — чек-лист

> Состояние: игра подготовлена (SDK-интеграция, комплаенс). Архив для загрузки собирает
> `python tools/build_release.py` → `releases/chronolift-yandex.zip` (~11 МБ, в git не хранится).
> Что осталось — действия в консоли разработчика Яндекс Игр (нужен Яндекс ID).
>
> Кто может публиковать: договор с Яндексом заключает любое физлицо, ИП или юрлицо РФ.
> Самозанятость не обязательна — она меняет только налог с выплат (6% вместо НДФЛ),
> выплаты от 3000 ₽. См. yandex.ru/dev/games/doc/ru/payments/self-employed.

---

## 1. Регистрация и кабинет

1. Зайдите в консоль **https://games.yandex.ru/console/** под Яндекс ID → «Добавить игру».
2. Заполните карточку: название «ХРОНОЛИФТ», описание, категория «Аркады», возрастной рейтинг 0+.
3. Промоматериалы:
   - иконка **512×512** (сгенерируйте из спрайта игрока на контрастном фоне);
   - обложка **800×470**;
   - 3–5 скриншотов 1280×720 (возьмите из `test/play_lesson_*.png`, приведите к 16:9).

## 2. Загрузка билда

1. Вкладка **Черновик → Общее** → загрузить `releases/chronolift-yandex.zip` (`index.html` — в корне архива ✓).
2. Платформы: десктоп + мобильный веб. Ориентация: **портрет** (игра 480×800 FIT).
3. Языки: русский (EN — позже; язык читается из `ysdk.environment.i18n.lang`, код готов).
4. Включите флажок **«Игра использует облачные сохранения»**.

## 3. Включение сервисов в консоли (обязательно до модерации)

| Сервис | Где включить | Что настроить |
|---|---|---|
| **Лидерборд** | Черновик → Лидерборды | Создать `chronolift_floors`, сортировка «больше = лучше», формат целое |
| **Платежи** | Черновик → Платежи | Каталог из 3 товаров: `remove_ads` (99 ₽), `coins_pack` (49 ₽), `skin_gold` (149 ₽) — ID совпадают с `ShopScene.js` |
| **Реклама** | Черновик → Реклама | Rewarded + Fullscreen блоки (AdFox/RSY) — игре достаточно дефолтных блоков |
| **Сохранения** | включён флажком выше | — |

## 4. Чек-лист модерации (проверено по официальным требованиям)

- [x] **SDK встроен** и инициализируется по документации (`YaGames.init()`).
- [x] **`LoadingAPI.ready()`** вызывается при готовности (`Boot.js`).
- [x] **`game_api_pause`/`game_api_resume`** — звук приостанавливается, игровой цикл засыпает (`Boot.js`).
- [x] **`GameplayAPI.start()/stop()`** вокруг rewarded и interstitial (`AdsService.js`).
- [x] **Гостевой вход** — играется без авторизации, прогресс сохраняется локально.
- [x] **Авторизация** — только по кнопке на welcome-экране, с описанием выгоды (облако, лидерборд).
- [x] **Платежи только через SDK**; внешних ссылок и микротранзакций нет.
- [x] **Потеря фокуса** — звук останавливается (веб-аудио контекст + loop.sleep).
- [x] **Автоопределение языка** через `environment.i18n.lang`.
- [x] **Нарастающая сложность + сеттинг** (5 уроков → комбо-этажи; ретеншн-цикл: рекорды/скины).
- [x] **Размер** 12,8 МБ в распакованном виде при лимите 100 МБ; 60 fps на целевых устройствах.

## 5. Тестирование перед отправкой

1. **Черновик доступен по закрытой ссылке** — откройте её с телефона (Яндекс.Браузер, Chrome Android).
2. Проверьте: загрузка → welcome → игра 3 забега → скины/магазин → возрождение за рекламу → ×2 монеты → рестарт.
3. Проверьте покупку в **дебаг-режиме платежей** (консоль Яндекса → «Песочница»): `remove_ads` отключает межсессионную рекламу, «Восстановить покупки» подтягивает список.
4. Локальная эмуляция SDK уже прогнана: `game/test-yandex.html` (мок `test/mock-yandex.js`) — init, облако, лидерборд, платежи, пауза, реклама.

## 6. Отправка и сроки

1. «Отправить на модерацию». Обычно **3–5 рабочих дней** (контент-чек промо ~2 дня).
2. При отклонении — причины приходят на почту; исправить и отправить повторно.
3. Совет: включите **отсроченную публикацию**, чтобы контролировать день релиза.

## 7. После публикации

- Метрики: Яндекс.Метрика подключена через `AnalyticsService` (кольцевой буфер событий; добавьте ID счётчика в `index.html` при желании).
- Софт-запуск 1 неделя → смотреть `run_death` (причины), конверсию revive, D1-retention → баланс `Config.js` (drainRate/speedPerFloor).
